💱 Currency Converter

A responsive and interactive Currency Converter web application built using HTML, CSS, and JavaScript. It allows users to convert an amount from one currency to another using real-time exchange rate data from an external API.

🚀 Features

- 💰 Convert between different world currencies.
- 🌍 Supports multiple international currencies.
- 🔄 Select source and target currencies.
- 💵 Enter a custom amount for conversion.
- 🌐 Fetch exchange rates using an external API.
- 🏳️ Display country flags based on selected currencies.
- ⚡ Dynamic conversion results.
- 🎨 Simple and user-friendly interface.
- 📱 Responsive design for different screen sizes.

🛠️ Technologies Used

- HTML5 – Application structure.
- CSS3 – Styling and responsive design.
- JavaScript (ES6) – Application logic and DOM manipulation.
- Currency Exchange API – Fetching exchange rate data.

⚙️ How to Run the Project

1. Clone this repository:
   
   git clone YOUR_REPOSITORY_URL

2. Navigate to the project folder.

3. Open "index.html" in your browser.

4. Enter the amount you want to convert.

5. Select the source and target currencies.

6. Get the converted amount.
